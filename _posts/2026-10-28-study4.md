기억장치 단원은 **개념 암기 + 계산 문제**가 함께 나오는 영역입니다. 특히 DRAM/SRAM 비교, 캐시 사상 방식, 평균 접근 시간 계산이 중요합니다.


## 1. 기억장치 계층 구조

### 1-1. 계층 구조가 필요한 이유
**빠르고 큰 용량의 저렴한 메모리는 존재하지 않기 때문**입니다. 속도, 용량, 가격이 서로 상충하므로 여러 종류의 기억장치를 계층적으로 배치해 **마치 빠르고 큰 메모리처럼** 동작하게 만듭니다.

### 1-2. 계층 구조

```
  빠름·비쌈·소용량                         느림·저렴·대용량
  ┌────────┐  ┌──────┐  ┌────────┐  ┌────────────┐  ┌──────────┐
  │ 레지스터│ →│  캐시 │→│ 주기억장치│→│ 보조기억장치 │→│ 대용량/백업 │
  └────────┘  └──────┘  └────────┘  └────────────┘  └──────────┘
   (CPU 내부)  (SRAM)     (DRAM)      (HDD, SSD)      (테이프, 광디스크)
```

- 메모리 계층화 이유 : 메모리간 속도 차이 문제를 해결하기 위해. 캐시에 가장 먼저 접근하고 없으면 메인메모리에 접근. 메인메모리에도 없으면 보조기억장치에서 메인메모리로 불러옴

<br>

| 계층 | 특징 |
|---|---|
| **레지스터** | CPU 내부, 가장 빠르고 용량이 가장 작음 |
| **캐시 메모리** | CPU와 주기억장치 간 속도 차이 완화, SRAM 사용 |
| **주기억장치** | CPU가 직접 접근, RAM과 ROM으로 구성 |
| **보조기억장치** | 대용량 영구 저장, CPU가 직접 접근하지 못함 |

**위로 갈수록**: 속도 ↑, 비트당 가격 ↑, 용량 ↓    <br>
**아래로 갈수록**: 속도 ↓, 비트당 가격 ↓, 용량 ↑

### 1-3. 계층 구조가 효과를 내는 이유: 지역성의 원리 (Locality)

| 지역성 | 의미 | 예시 |
|---|---|---|
| **시간적 지역성** | 한 번 접근한 데이터는 **곧 다시 접근**할 가능성이 높음 | 반복문, 카운터 변수, 서브루틴 |
| **공간적 지역성** | 접근한 주소의 **근처**를 접근할 가능성이 높음 | 배열 순회, 연속된 데이터 |
| **순차적 지역성** | 명령어가 **순차적으로** 실행되는 경향 | 분기가 없는 코드의 순차 실행 |

> 캐시가 효과적인 근거가 바로 이 지역성입니다. 자주 쓰는 데이터와 그 주변 블록을 미리 캐시에 가져다 놓으면 적중률이 높아집니다.

## 2. 주기억장치

CPU가 **직접 접근**할 수 있는 기억장치로, **RAM**과 **ROM**으로 구분합니다.

### 2-1. RAM (Random Access Memory)
- **읽기/쓰기가 모두 가능**한 **휘발성** 메모리 (전원이 꺼지면 내용 소멸)
- 어느 위치든 접근 시간이 동일한 **임의 접근** 방식

#### DRAM vs SRAM (필수 비교)

| 구분 | DRAM (동적) | SRAM (정적) |
|---|---|---|
| 저장 소자 | **콘덴서(캐패시터)** | **플립플롭** |
| 재충전(리프레시) | **필요** | 불필요 |
| 속도 | 상대적으로 느림 | **빠름** |
| 집적도 | **높음** | 낮음 |
| 가격 | 저렴 | **비쌈** |
| 소비 전력 | 상대적으로 적음 | 상대적으로 많음 |
| 용도 | **주기억장치** | **캐시 메모리**, 레지스터 |

> **DRAM은 콘덴서의 전하가 시간이 지나면 방전**되므로 주기적으로 다시 써 주는 **리프레시**가 필요합니다. 이 때문에 SRAM보다 느립니다.

#### DRAM의 발전
- **SDRAM**: 시스템 클럭에 **동기**해서 동작
- **DDR SDRAM**: 클럭의 **상승 에지와 하강 에지 모두**에서 데이터를 전송해 같은 클럭에서 **2배 대역폭** (DDR → DDR2 → DDR3 → DDR4 → DDR5로 발전)

### 2-2. ROM (Read Only Memory)
- **읽기 전용**의 **비휘발성** 메모리 (전원이 꺼져도 내용 유지)
- 용도: **BIOS(부팅 프로그램), 펌웨어, 마이크로프로그램(제어 메모리)**

| 종류 | 특징 |
|---|---|
| **Mask ROM** | 제조 단계에서 내용을 기록, **수정 불가** |
| **PROM** | 사용자가 **한 번만** 기록 가능 |
| **EPROM** | **자외선**으로 전체 소거 후 재기록 |
| **EEPROM** | **전기적**으로 소거·재기록 (바이트 단위) |
| **플래시 메모리** | EEPROM의 일종, **블록 단위**로 소거·기록, 비휘발성 |

#### 플래시 메모리: NOR vs NAND

| 구분 | NOR형 | NAND형 |
|---|---|---|
| 접근 | 임의 접근, 읽기 빠름 | 페이지 단위 접근 |
| 집적도·용량 | 낮음 | **높음 (대용량, 저가)** |
| 용도 | 코드 저장(펌웨어) | **SSD, USB, 메모리카드** |

### 2-3. RAM과 ROM 한눈에 비교

| 구분 | RAM | ROM |
|---|---|---|
| 읽기/쓰기 | 모두 가능 | 읽기 중심 |
| 휘발성 | **휘발성** | **비휘발성** |
| 용도 | 프로그램·데이터 임시 저장 | 부팅·펌웨어 |

### 2-4. 기억장치 용량 계산

**용량 = 기억 장소(워드) 수 × 워드 길이**, 주소 비트가 n이면 **2ⁿ개**의 주소를 지정할 수 있습니다.

> 예) 주소 버스 16비트, 워드 길이 8비트  <br>
> 2¹⁶ = 65,536개 = 64K 워드 → **64K × 8비트 = 64KB**

## 3. 캐시 메모리 (Cache Memory)

### 3-1. 개념과 목적
- CPU와 주기억장치 사이에 위치한 **고속의 소용량 버퍼 메모리** (SRAM으로 구성)
- 목적: **CPU와 주기억장치 간의 속도 차이를 줄여** 평균 접근 시간을 단축

### 3-2. 적중(Hit)과 실패(Miss)

- **Hit**: CPU가 원하는 데이터가 캐시에 있음
- **Miss**: 캐시에 없어 주기억장치에서 가져와야 함
- **적중률(H) = 캐시 적중 횟수 ÷ 전체 접근 횟수**

**평균 기억장치 접근 시간 = (H × Tc) + ((1 − H) × Tm)**
(Tc: 캐시 접근 시간, Tm: 주기억장치 접근 시간)

> 예) Tc = 10ns, Tm = 100ns, H = 0.9  <br>
> → (0.9 × 10) + (0.1 × 100) = 9 + 10 = **19ns**  <br>
> 적중률이 높을수록 평균 접근 시간이 캐시 접근 시간에 가까워집니다.

#### 캐시 미스의 종류 (3C)
- **강제 미스(Compulsory)**: 처음 접근하는 블록이라 당연히 없음
- **용량 미스(Capacity)**: 캐시 용량이 부족해 발생
- **충돌 미스(Conflict)**: 서로 다른 블록이 같은 캐시 위치에 사상되어 발생

### 3-3. 사상(Mapping) 방식
주기억장치의 블록을 **캐시의 어느 위치에 넣을지** 결정하는 방식입니다.

| 방식 | 동작 | 장점 | 단점 |
|---|---|---|---|
| **직접 사상** | 각 블록이 **정해진 한 라인**에만 들어감 | 구현 간단, 빠름 | **충돌 미스** 많음, 적중률 낮음 |
| **연관(완전 연관) 사상** | 블록을 **캐시의 어느 라인에나** 저장 | 적중률 높음, 유연 | 모든 태그를 비교해야 해서 **하드웨어 복잡·고가**, 교체 알고리즘 필요 |
| **세트 연관 사상** | 블록이 **정해진 세트 안**에서 어느 라인에나 저장 | 직접과 연관의 **절충** | 중간 정도의 복잡도 |

#### 직접 사상의 주소 구조

```
 주소 = [   태그(Tag)   |  인덱스(Index/Line)  |  오프셋(Offset)  ]
```

- **오프셋**: 블록(라인) 내부의 바이트 위치
- **인덱스**: 캐시의 몇 번째 라인인지
- **태그**: 해당 라인에 **어느 주기억장치 블록이 들어 있는지** 구분

> 예) 주기억장치 64KB(주소 16비트), 라인 크기 16B, 캐시 라인 수 256개
> - 오프셋 = log₂16 = **4비트**  
> - 인덱스 = log₂256 = **8비트**
> - 태그 = 16 − 4 − 8 = **4비트**
> - 캐시 용량 = 256 × 16B = **4KB**

### 3-4. 교체 알고리즘
캐시가 가득 찼을 때 **어느 블록을 내보낼지** 결정합니다. (직접 사상은 위치가 정해져 있어 교체 알고리즘이 필요 없음)

| 알고리즘 | 기준 |
|---|---|
| **FIFO** | 가장 **먼저 들어온** 블록 교체 |
| **LRU** | **가장 오랫동안 사용되지 않은** 블록 교체 (시간적 지역성 활용) |
| **LFU** | **사용 횟수가 가장 적은** 블록 교체 |
| **Random** | 무작위로 교체 |

### 3-5. 쓰기 정책 (Write Policy)
캐시의 데이터가 수정될 때 **주기억장치와의 내용 일치**를 어떻게 처리할지 정하는 방식입니다.

| 구분 | Write-Through | Write-Back |
|---|---|---|
| 방식 | 캐시와 주기억장치에 **동시에** 기록 | **캐시에만** 기록, 해당 블록이 교체될 때 주기억장치에 반영 |
| 일관성 | 항상 유지 | 일시적으로 **불일치** 발생 |
| 속도 | 쓰기가 느림, 버스 사용량 많음 | 쓰기가 빠름, 버스 사용량 적음 |
| 구현 | 단순 | **Dirty bit** 필요 (수정 여부 표시) |

### 3-6. 캐시의 계층
- **L1 캐시**: CPU 코어 내부, 가장 빠르고 작음 (명령어 캐시와 데이터 캐시로 분리하는 경우가 많음) (수 KB ~ 수십 KB, CPU 내장형)
- **L2 캐시**: L1보다 크고 느림 (수백 KB ~ 수 MB, CPU 내장형 또는 외장형)
- **L3 캐시**: 여러 코어가 **공유**, 가장 크고 상대적으로 느림 (수 MB ~ 수십 MB, 보통 CPU 외부에 위치하거나 다중 코어 간 공유)

> 멀티코어 환경에서는 코어마다 캐시가 있어 **캐시 일관성(Cache Coherence)** 문제가 생기며, 이를 하드웨어 프로토콜로 해결합니다.

## 4. 보조기억장치

### 4-1. HDD (하드디스크)
- 구조: **플래터(원판), 트랙(동심원), 섹터(트랙의 분할 단위), 실린더(같은 위치의 트랙 묶음), 헤드**
- **접근 시간 = 탐색 시간(Seek) + 회전 지연 시간(Latency) + 전송 시간(Transfer)**
  - 탐색 시간: 헤드를 원하는 트랙으로 이동하는 시간
  - 회전 지연 시간: 원하는 섹터가 헤드 아래로 오기까지의 시간
  - 전송 시간: 데이터를 실제로 읽고 쓰는 시간

### 4-2. SSD vs HDD

| 구분 | HDD | SSD |
|---|---|---|
| 저장 방식 | 자기 디스크 | **NAND 플래시 메모리** |
| 기계적 부품 | 있음 (모터, 헤드) | **없음** |
| 속도 | 느림 | **빠름** |
| 충격·소음 | 약함·있음 | **강함·없음** |
| 용량당 가격 | **저렴** | 상대적으로 비쌈 |
| 수명 | 기계적 마모 | 쓰기 횟수 제한 |

## 5. 기억장치 관련 기법

| 기법 | 설명 |
|---|---|
| **메모리 인터리빙** | 메모리를 여러 **뱅크**로 나누어 **동시에 접근**, 접근 속도 향상 |
| **연관 기억장치 (CAM)** | **주소가 아닌 내용**으로 접근하는 메모리, 병렬 검색 가능 (캐시 태그 검색에 활용) |
| **가상 메모리** | 보조기억장치 일부를 주기억장치처럼 사용해 **실제 메모리보다 큰 주소 공간** 제공 |

<br>

## 6. 시험 대비 핵심 정리

1. 계층 구조: **레지스터 → 캐시 → 주기억 → 보조기억**, 위로 갈수록 빠르고 비싸고 작음
2. 계층 구조의 원리는 **지역성** (시간적·공간적·순차적)
3. **DRAM**은 콘덴서·**리프레시 필요**·주기억장치, **SRAM**은 플립플롭·빠름·**캐시**
4. ROM 계열: Mask ROM → PROM(1회) → **EPROM(자외선)** → **EEPROM(전기)** → 플래시(블록 단위)
5. 평균 접근 시간 = **H×Tc + (1−H)×Tm**
6. 사상 방식은 **직접(단순, 충돌), 연관(유연, 복잡), 세트 연관(절충)**
7. 교체 알고리즘은 **FIFO, LRU, LFU, Random**, 직접 사상은 교체 불필요
8. **Write-through는 즉시 반영(일관성)**, **Write-back은 교체 시 반영(속도, Dirty bit)**
9. 기억장치 용량 = **2^(주소 비트) × 워드 길이**
10. HDD 접근 시간 = **탐색 + 회전 지연 + 전송**
